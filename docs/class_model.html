詳解

Assimp で読み込んだ 3D モデルを管理する基底クラス

ノード階層をトラバースしてメッシュを構築し、 ワールドトランスフォーム（位置・回転・スケール・ピボット）を提供する。 マテリアルの初期化はサブクラスが実装する。
